OMNIGUARD — WINDOWS QUICK START

1. Double-click 1_START_OMNIGUARD.bat
2. Wait while prebuilt Python packages are checked/installed.
3. The website opens automatically at http://127.0.0.1:8000
4. Enter your Groq API key on the website and click Test key.

This v12 build is optimized for Python 3.14 and prevents pip from compiling pydantic-core from source.

To stop the app, close the black window or press Ctrl+C.
